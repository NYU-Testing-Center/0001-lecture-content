# CS0002 Lecture Content

This repository contains the lecture materials and presentation runtime for NYU CS0002. It is a lecture-only repository: PrairieLearn questions, solutions, graders, rubrics, and answer keys are intentionally stored elsewhere.

## Open the lectures in GitHub Codespaces

1. On GitHub, open **Code → Codespaces → Create codespace on main**.
2. Wait for the environment to finish configuring. JupyterLab starts automatically, and the terminal prints the authenticated Jupyter URL.
3. Open that URL, then choose a notebook under `notebooks/cs1/`.
4. Click inside the notebook and press `Esc`, then start RISE:
   - macOS: `Option` + `R`
   - Windows/Linux: `Alt` + `R`

In RISE, runnable code cells display a Francis-style **Run** button. Clicking it executes the real notebook cell, keeps the output attached to that cell, and does not advance the presentation.

Amber **🧪 In-Class Exercise** cards are signposts to the corresponding PrairieLearn assessment. Follow the link on the card to complete the activity in PrairieLearn.

## Repository boundary

This repository contains lecture notebooks, lecture images, deterministic notebook-generation sources, and the Codespaces/JupyterLab/RISE runtime only. It intentionally does **not** contain PrairieLearn question implementations, solutions, graders, tests, rubrics, or answer keys.

The official PrairieLearn repository remains [PrairieLearn/pl-nyu-cs1](https://github.com/PrairieLearn/pl-nyu-cs1).
